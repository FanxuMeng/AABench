# AA-LCR 下载与上传说明

更新：2026-10-17。工具适用于 macOS / Linux，要求 Python 3.9 或以上，无需 pip、Git LFS、Hugging Face 账号或 GPU。Windows 可在 WSL 中下载。

数据来自 [Artificial Analysis 官方 AA-LCR 仓库](https://huggingface.co/datasets/ArtificialAnalysis/AA-LCR)。核查版本为 v1.1，完整 commit：`9a77ef56b717057ade24ceab4d273712a0b4f19e`。脚本默认固定这个版本，避免评测数据在恢复下载时变化。

官方仓库约 4.19MB，其中包括题目 CSV 和约 4.02MB 的上下文 ZIP。不能只下载 CSV；预提取文本已经放在 ZIP 内，无需重新抓取题目中列出的原始 PDF。[官方文件树](https://huggingface.co/datasets/ArtificialAnalysis/AA-LCR/tree/9a77ef56b717057ade24ceab4d273712a0b4f19e)

## 本地下载

在终端进入本说明与 `download_aa_lcr.py` 所在目录，执行：

```bash
python3 download_aa_lcr.py --output ./AA-LCR
```

当前聊天生成的文件夹是：

```bash
cd /Users/fanxumeng/Documents/Codex/2026-10-16/artificial-analysis-artificial-analysis/outputs/aa_lcr_downloader
python3 download_aa_lcr.py --output ./AA-LCR
```

网络中断、终端关闭或按 Ctrl-C 后，**再次执行同一条命令**即可恢复。不要删除 `.aa_lcr_download`，其中存有固定版本、远端文件清单及 `.part` 残片。

脚本会重新校验已完成文件并跳过，使用 HTTP Range 从残片位置继续请求尚未完成的文件。如果服务端忽略 Range，脚本会安全地从头下载该文件，不把两份内容错误拼接。出现超时、429 或可恢复服务错误时默认最多重试 5 次；重试耗尽仍保留进度。Ctrl-C 退出码为 130，失败为 1，成功为 0。

慢网络可以调整超时和重试次数：

```bash
python3 download_aa_lcr.py --output ./AA-LCR --timeout 120 --retries 10
```

成功后的目录大致如下：

```text
AA-LCR/
├── .gitattributes
├── AA-LCR_Dataset.csv
├── README.md
├── extracted_text/
│   └── AA-LCR_extracted-text.zip
└── .aa_lcr_download/
    ├── state.json       # 完整commit、远端预期文件列表、大小和哈希
    ├── manifest.json    # 完成后生成的SHA256校验清单
    ├── download.lock    # 并发保护；进程退出时自动解锁
    └── partials/       # 未完成文件的残片
```

只有全部预期文件通过大小和上游哈希检查，脚本才生成完成清单。普通 Git 文件检查 Git blob SHA-1，LFS 文件检查内容 SHA256，另为所有文件记录 SHA256 便于上传后校验。损坏文件不会被简单重新计算哈希“洗成正常”，重新运行下载命令会定向修复。

## 本地离线校验

```bash
python3 download_aa_lcr.py --output ./AA-LCR --verify-only
```

这条命令不访问网络，也不修改文件。缺文件、大小不符、内容改变、清单不完整都会失败。应在上传前看到“离线校验通过”。校验用于发现损坏和传输错误，不是对本地文件及清单同时被恶意替换的数字签名保证。

## 上传到云服务器，并支持恢复传输

以下 `USER`、`SERVER_IP`、`PORT` 和 `/data/datasets/AA-LCR` 是占位符，请替换为服务器实际账号、地址、SSH 端口和有写权限的目录。若使用 SSH 私钥，可给 SSH 命令添加 `-i /path/to/key`。

先创建远端目录：

```bash
ssh -p PORT USER@SERVER_IP 'mkdir -p /data/datasets/AA-LCR'
```

上传数据目录，**保留两个 JSON 校验文件**，排除下载临时文件：

```bash
rsync -avP -e "ssh -p PORT" \
  --exclude='.aa_lcr_download/partials/' \
  --exclude='.aa_lcr_download/download.lock' \
  --exclude='*.tmp' \
  ./AA-LCR/ USER@SERVER_IP:/data/datasets/AA-LCR/
```

`-P` 保留未完成传输并显示进度。上传中断后重新运行同一条 rsync 命令；rsync 会利用已有内容进行恢复。源路径末尾 `/` 表示上传目录中的内容，避免多套一层 `AA-LCR/AA-LCR`。

再上传校验脚本：

```bash
scp -P PORT ./download_aa_lcr.py USER@SERVER_IP:/data/datasets/
```

在云服务器离线校验：

```bash
ssh -p PORT USER@SERVER_IP \
  'python3 /data/datasets/download_aa_lcr.py --output /data/datasets/AA-LCR --verify-only'
```

数据已放在自己的服务器上，无需将它上传到 Hugging Face。远端不需要外网，也无需安装任何 Python 包，只需 Python 3.9+；rsync 传输需要本地和服务器均安装 rsync。

如果远端校验失败而本地通过，可增加 `--checksum` 重跑上述 rsync，使它不只按文件大小和修改时间判断是否需要更新，再做离线校验。没有 rsync 时可使用 `scp -r`，但 scp 不提供同样的恢复传输体验。

## 解压并读取上下文

下载工具保留官方 ZIP 原样，不自动修改或解压评测数据。完成校验后，可在本地或服务器查看 ZIP 内容，再解压到独立目录：

```bash
python3 -m zipfile -l ./AA-LCR/extracted_text/AA-LCR_extracted-text.zip
python3 -m zipfile -e ./AA-LCR/extracted_text/AA-LCR_extracted-text.zip ./AA-LCR/context
```

使用 CSV 的 `document_category`、`document_set_id` 和 `data_source_filenames` 定位文本，按照 `data_source_filenames` 中分号分隔的顺序拼接文档；实际前缀层级以解压结果为准，不仅凭文件名猜路径。`data_source_urls` 提供原始出处。[官方加载示例](https://huggingface.co/datasets/ArtificialAnalysis/AA-LCR/blob/9a77ef56b717057ade24ceab4d273712a0b4f19e/README.md)

下载后的原始 ZIP/CSV 在校验范围内，后续生成的 `context/` 不在本脚本的清单内。问题集许可与来源文档权利范围不同，使用与分发时参考下载的官方 README。

AA-LCR 的完整输入大多接近 100k tokens；文件只有数 MB 不代表推理所需显存也小。此前短上下文的 8B/24GB 配置不能直接视为已经满足完整 AA-LCR 的推理条件，后续需单独验证上下文长度与显存。[AA-LCR 数据说明](https://huggingface.co/datasets/ArtificialAnalysis/AA-LCR)

## 版本与常见问题

- **要下载最新 main**：使用新的输出目录运行 `python3 download_aa_lcr.py --revision main --output ./AA-LCR-new`。首次解析为完整 commit，后续恢复仍使用该 commit。不要为同一目录混用不同 revision。
- **目录已锁定其他版本**：换新的 `--output`。不要只删除状态文件后混入旧文件。
- **找不到模块**：本脚本没有第三方依赖；先确认 `python3 --version` 至少为 3.9。
- **DNS、连接超时**：先确保本地可以访问 Hugging Face 及其下载 CDN。脚本支持 urllib 使用的标准 `HTTPS_PROXY` / `HTTP_PROXY` 环境变量，但不自动更改代理或切换第三方镜像。
- **TLS 证书问题**：修复 Python 的证书安装或企业代理证书配置；不要关闭 HTTPS 验证。
- **下载进程已退出，但 lock 文件仍在**：正常。文件存在不代表仍持锁，锁随进程退出自动释放。
- **磁盘不足**：释放足够空间后重跑同一命令，已保存的残片仍可用。
- **日志与隐私**：脚本不读取 Hugging Face token、SSH 密钥或浏览器登录信息；SSH 上传凭证由本地 ssh/scp/rsync 管理。
